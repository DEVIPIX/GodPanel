# ⚡ GodPanel

> یک تم‌ساز زیبا برای پنل X-UI (سنایی) با ۷ تم رنگی دست‌ساز.

GodPanel یک اسکریپت سبک است که در چند ثانیه ظاهر پنل X-UI شما را کاملاً متحول می‌کند.
از میان تم‌های به‌دقت طراحی‌شده یکی را انتخاب کنید و به پنل خود ظاهری مدرن و لوکس بدهید، بدون اینکه نیازی به دستکاری کد اصلی باشد.
